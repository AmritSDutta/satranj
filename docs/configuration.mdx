# Configuration

## Environment Variables

Create a `.env` file in the project root (use `.env.example` as a template):

### Required Variables

| Variable | Description | Example |
|----------|-------------|---------|
| `VITE_FARO_COLLECTOR_URL` | Grafana Faro collector endpoint URL | `https://faro-collector-prod-ap-south-1.grafana.net/collect/your-key` |
| `FARO_API_KEY` | API key for uploading source maps | `a5f19c2684ab297f27fc603bf82a0e92` |

> **Note:** `FARO_API_KEY` is only needed if using the `@grafana/faro-rollup-plugin` for source map uploads. The app will run without it.

## Vite Configuration

**File:** `vite.config.js`

```javascript
export default defineConfig({
  plugins: [
    react(),
    faroUploader({
      appName: 'satranj.amritai.org',
      endpoint: 'https://faro-api-prod-ap-south-1.grafana.net/faro/api/v1',
      appId: '1960',
      stackId: '1619876',
      verbose: true,
      apiKey: process.env.FARO_API_KEY,
      gzipContents: true,
    })
  ],
  server: {
    host: true,  // Bind to 0.0.0.0 for network access
  }
})
```

### Key Settings

| Setting | Value | Purpose |
|---------|-------|---------|
| `server.host` | `true` | Exposes dev server to LAN |
| `faroUploader.appName` | `satranj.amritai.org` | Matches Faro app metadata |
| `faroUploader.gzipContents` | `true` | Compresses source maps before upload |

## Dev Server Plugins (WebMCP & Proxy)

`vite.config.js` registers a local plugin (`viteWebMcpPlugin`) that mounts four middleware routes used only in development (`import.meta.env.DEV`):

| Endpoint | Method | Purpose |
|----------|--------|---------|
| `/api/mcp/sse` | GET | SSE stream pushing `chat_message` and `highlight_board` events to the browser |
| `/api/mcp/message` | POST | JSON-RPC 2.0 dispatcher for external MCP clients |
| `/api/mcp/state` | GET / POST | Browser→host state sync for external tools |
| `/api/proxy` | POST | Same-origin proxy for AI provider hosts |

The `/api/proxy` route enforces a **host allow-list**; requests to other hosts return `403`:

```text
generativelanguage.googleapis.com · api.openai.com · openai.com
ollama.com · api.mistral.ai · router.requesty.ai
api.tokenfactory.nebius.com · openrouter.ai
```

`localhost` / `127.0.0.1` targets are also allowed for local Ollama. See [WebMCP Integration](/webmcp) for the full endpoint behavior.

## Content-Security-Policy

`index.html` sets a CSP `<meta>` tag. The `connect-src` directive must list every origin the app may contact, so adding a provider means extending it:

```text
default-src 'self';
connect-src 'self'
  https://faro-api-prod-ap-south-1.grafana.net
  https://faro-collector-prod-ap-south-1.grafana.net
  https://generativelanguage.googleapis.com
  https://api.openai.com
  https://ollama.com
  https://api.mistral.ai
  https://router.requesty.ai
  https://api.tokenfactory.nebius.com
  https://openrouter.ai
  http://localhost:* ws://localhost:*;
```

The global security headers (`X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`) and the `Access-Control-Allow-*` headers for `/api/*` are defined in `public/_headers` for hosts that support it.

## Coach Provider Credentials

The AI Coach stores provider settings in the browser, encrypted with AES-GCM-256 (see [AI Coach](/coach)). They are **not** environment variables and cannot be supplied at build time.

| Setting | Default | Notes |
|---------|---------|-------|
| Provider | `gemini` | `gemini` \| `openrouter` \| `nebius` \| `openai` \| `ollama` |
| Gemini model | `gemini-2.5-flash` | Editable in the drawer |
| OpenRouter model | `openrouter/free` | Reasoning enabled; endpoint `https://openrouter.ai/api/v1` |
| Nebius model | `MiniMaxAI/MiniMax-M3.1-Flash` | Endpoint `https://api.tokenfactory.nebius.com/v1` |
| OpenAI model | `gpt-4o-mini` | Editable in the drawer |
| Ollama model | `llama3.2` | Endpoint defaults to `http://localhost:11434` |

## Grafana Faro Integration

Satranj integrates **Grafana Faro** for Real User Monitoring (RUM), error tracking, and performance telemetry.

### Initialization (`src/main.jsx`)

```javascript
initializeFaro({
  url: import.meta.env.VITE_FARO_COLLECTOR_URL || 'fallback-url',
  app: {
    name: 'satranj.amritai.org',
    version: '1.0.0',
    environment: 'production',
  },
  instrumentations: [
    ...getWebInstrumentations(),
    new TracingInstrumentation({
      instrumentationOptions: {
        propagateTraceHeaderCorsUrls: [/satranj\.amritai\.org/],
      },
    }),
    new ReactIntegration(),
  ],
});
```

### Instrumentations

| Instrumentation | Purpose |
|-----------------|---------|
| `getWebInstrumentations()` | Console logs, JS errors, web vitals, session tracking |
| `TracingInstrumentation` | OpenTelemetry HTTP request tracing (restricted to `satranj.amritai.org`) |
| `ReactIntegration` | Component stack traces in error reports |

### Error Boundary (`src/App.jsx`)

The `<FaroErrorBoundary>` wraps the entire dashboard:

```jsx
<FaroErrorBoundary fallback={<CrashUI />}>
  <Dashboard />
</FaroErrorBoundary>
```

Crashes are automatically reported to Faro with React component stack traces.

## Linting

**File:** `.oxlintrc.json`

```json
{
  "plugins": ["react", "oxc"],
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }]
  }
}
```

Rules enforced:

| Rule | Level | Description |
|------|-------|-------------|
| `react/rules-of-hooks` | error | Prevents invalid hook usage |
| `react/only-export-components` | warn | Ensures only components are exported (with constant export exception) |

## Git Ignore

The following are excluded from version control:

- `node_modules/`, `dist/`, `dist-ssr/`
- `.env*` files (environment secrets)
- `*.local` files
- Editor directories (`.vscode/`, `.idea/`, `.DS_Store`)
- Log files (`*.log`, `npm-debug.log*`)
