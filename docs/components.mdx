# Components

## Dashboard

**File:** `src/components/Dashboard.jsx` (~1070 lines)

The main game container and orchestrator. Manages all game state, handles move execution, and renders the complete game UI including setup screen.

### Responsibilities

- **Game state management**: Chess.js instance, FEN, move history, history FENs
- **Stockfish AI integration**: Move calculation and evaluation
- **Move validation and execution**: `executeMove()`, `makeAIMove()`
- **UI mode switching**: Setup screen vs. active game interface
- **Game controls**: Pause/resume, undo, flip board, restart, return to setup
- **Game over detection**: Checkmate, stalemate, timeout, draw conditions
- **WebMCP bridge**: Registers the `ActiveGameBridge` for tools and the coach
- **Board annotations**: Renders `customSquareStyles` and `customArrows`
- **Arrow normalization**: `normalizeArrows()` coerces tool-supplied arrows — `[from, to, color]` tuples or `{ startSquare, endSquare, color }` objects — into `react-chessboard`'s schema, validating squares so malformed coordinates never crash rendering
- **Persistence**: Auto-saves the active game and offers resume from the setup screen
- **Theme mode**: Toggles dark/light via `data-theme`

### Props

None — Dashboard is the root component rendered by `<App />`.

### Key Methods

| Method | Description |
|--------|-------------|
| `executeMove(from, to, san)` | Validates and applies a move, updates all state |
| `makeAIMove(uciMove)` | Parses UCI notation and calls `executeMove` |
| `handleAnalyzeGame()` | Runs Stockfish analysis across all game positions |
| `handleResumeGame(saved)` | Restores a saved game, paused, from `localStorage` |
| `selectMoveIndex(idx)` | Navigates to a specific position in move history |
| `handleUndo()` | Reverts the last move pair |
| `resetGame()` | Resets to initial position with current settings |

## ChessClock

**File:** `src/components/ChessClock.jsx`

Turn-synced countdown timers for both players.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `activeColor` | string | `'w'` or `'b'` — whose turn it is |
| `isGameOver` | boolean | Whether the game has ended |
| `onTimeout` | function | Callback when a clock reaches zero |
| `timePreset` | string | Preset identifier (e.g., `"10+0"`) |
| `gameHistoryLength` | number | Move count (for increment detection) |
| `resetTrigger` | number | Increment to force clock reset |
| `initialWhiteTime` | number | Optional seed for White's clock (resume) |
| `initialBlackTime` | number | Optional seed for Black's clock (resume) |
| `onTimeUpdate` | function | Reports `{ whiteTime, blackTime }` for persistence |

### Time Presets

| Preset | Initial Time | Increment |
|--------|-------------|-----------|
| `1+0` | 60,000 ms | 0 ms |
| `3+2` | 180,000 ms | 2,000 ms |
| `5+0` | 300,000 ms | 0 ms |
| `10+0` | 600,000 ms | 0 ms |
| `30+0` | 1,800,000 ms | 0 ms |

### Behavior

- **100ms tick interval** for millisecond-accurate countdown
- **Increment application**: Added to the player who just moved (detected via `gameHistoryLength` change)
- **Low-time warning**: CSS class `flagged` applied when < 20,000 ms
- **Tenths display**: Shows `.T` precision when < 10,000 ms
- **Timeout callback**: Calls `onTimeout(color)` when time expires

## EvaluationBar

**File:** `src/components/EvaluationBar.jsx`

Vertical bar displaying the current engine evaluation.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `evaluation` | object \| null | `{ type: 'cp'\|'mate', value: number }` |
| `isFlipped` | boolean | Board orientation (inverts bar) |

### Score Mapping

- **Centipawns**: Divided by 100 to get pawn units, then mapped from [-10, +10] to [5%, 95%]
- **Mate**: Capped at ±10, displayed as `M#` (mate in N moves)
- **Orientation**: When `isFlipped` is true, the bar inverts (Black percentage at bottom)

## CapturedPieces

**File:** `src/components/CapturedPieces.jsx`

Visual tracker of captured material.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `game` | Chess instance | Current game position |
| `playerColor` | string | `'w'` or `'b'` — perspective to display |

### Logic

1. Scans the board to count current pieces by type and color
2. Compares against starting counts to determine captured pieces
3. Displays the opponent's captured pieces from the player's perspective
4. Shows score difference using standard piece values (Q=9, R=5, B=3, N=3, P=1)

## CoachDrawer

**File:** `src/components/CoachDrawer.jsx`

A glassmorphic slide-out chat drawer that hosts the AI Coach. It renders the message stream, quick-action chips, provider settings, and clickable candidate-move pills.

### Props

| Prop | Type | Description |
|------|------|-------------|
| `isOpen` | boolean | Controls drawer visibility |
| `onClose` | function | Close handler |
| `activeGameBridge` | object | Bridge exposing game state and board highlighting |
| `onClearHighlights` | function | Clears all square tints and arrows |

### Behavior

- **Encrypted settings**: Loads/saves provider, API key, model, and endpoint via `cryptoStorage` on mount and on save.
- **Provider settings**: A dropdown for Google Gemini, OpenRouter, Nebius, OpenAI, and Ollama, with an endpoint field for the providers that need one and a saved/not-set indicator plus a Clear action for the current key.
- **Message stream**: Renders user and assistant bubbles, an assistant welcome message, and live messages pushed from WebMCP.
- **Subscriptions**: Subscribes to `subscribeChatMessages` on mount and replays `drainChatMessages()` so messages sent while closed are not lost.
- **Agent loop**: Sends the conversation plus tool declarations to the provider and runs up to **4 tool-calling turns** (see [AI Coach](/coach)).
- **Suggested moves**: Clicking a pill calls `activeGameBridge.highlightBoard` to preview the move's `from`/`to` squares and arrow.
- **Quick actions**: *Suggest Move*, *Evaluate Position*, and *Check Threats* send canned prompts.

### Rendering

The drawer only mounts its DOM when `isOpen` is true (`if (!isOpen) return null`), so no background traffic occurs while it is closed.
